# Week-2
# Student Grade Calculator

## 📌 Project Overview
The Student Grade Calculator is a Python program that takes student marks as input and assigns grades based on a predefined grading system. The program includes input validation, decision-making using conditional statements, loops, and functions.

---

## 🎯 Project Objectives
- Learn decision-making using if-elif-else statements
- Use loops for validation and repetition
- Create reusable functions
- Handle invalid user input gracefully
- Display encouraging messages based on performance

---

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code (VS Code)

---

## ⚙️ Setup Instructions

1. Install Python 3 from  
   https://www.python.org

2. Install Visual Studio Code from  
   https://code.visualstudio.com

3. Install the Python extension in VS Code.

4. Open the project folder in VS Code.

5. Open terminal and run:
   ```bash
   python grade_calculator.py
